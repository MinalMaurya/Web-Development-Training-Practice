# ShopCart – Shopping Cart Website

A simple shopping cart website developed using HTML, CSS, Bootstrap, and JavaScript. This project demonstrates product display, shopping cart management, quantity updates, and order confirmation.

## Features

- Product listing with images and prices.
- Search products by name.
- Product details page.
- Add products to the shopping cart.
- Increase and decrease product quantities.
- Remove products from the cart.
- Automatic subtotal and total calculation.
- Order confirmation.
- Order history display.

## Technologies Used

- HTML5
- CSS3
- Bootstrap 5
- JavaScript
- Browser Local Storage

## How to Run

1. Download or clone the repository.
2. Open the Shopping folder in VS Code.
3. Open `product.html` using Live Server.
4. Browse products and add them to your cart.
5. Manage quantities and confirm your order.
6. View your order history.

## Note

This is a frontend practice project. Cart and order information is stored using browser Local Storage. It does not include a backend, database, or real payment processing.
