# Web Development Training Practice

A collection of foundational web development exercises completed during hands-on technical training at SDAC Infotech.

## Projects

### 1. E-Learning Website

A multi-page educational website built using HTML and CSS.

Pages:
- Home
- About Us
- Contact Us
- Login
- Registration

### 2. CSS Experiments

Individual exercises exploring fundamental CSS concepts:
- Inline, Internal and External CSS
- Video Backgrounds
- CSS Box Model
- Basic Styling and Layout

### 3. Bootstrap Experiments

A collection of practical exercises using Bootstrap to create responsive web interfaces.

**Shopping Cart Website (ShopCart)**

A frontend shopping cart application featuring:
- Product listing with images and prices
- Product search functionality
- Product details page
- Add and remove products from cart
- Quantity management
- Automatic price calculation
- Order confirmation and order history

## Technologies Used

- HTML5
- CSS3
- Bootstrap 5
- JavaScript

## Learning Objectives

- Understand HTML document structure.
- Create multi-page websites.
- Build forms and navigation links.
- Apply CSS styling and layouts.
- Explore different CSS implementation methods.
- Create responsive interfaces using Bootstrap.
- Implement basic shopping cart functionality using JavaScript.

## Training Context

These exercises were developed as part of foundational web development training and hands-on practice at SDAC Infotech.
