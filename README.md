# Web Development Training Practice

A collection of foundational web development exercises completed during hands-on technical training at SDAC Infotech.

## Projects

### E-Learning Website
A multi-page educational website built using HTML and CSS.

Pages:
- Home
- About Us
- Contact Us
- Login
- Registration

### CSS Experiments

Individual exercises exploring fundamental CSS concepts:
- Inline, Internal and External CSS
- Video Backgrounds
- CSS Box Model
- Basic Styling and Layout

## Technologies Used
- HTML5
- CSS3

## Learning Objectives
- Understand HTML document structure.
- Create multi-page websites.
- Build forms and navigation links.
- Apply CSS styling and layouts.
- Explore different CSS implementation methods.

## Training Context

These exercises were developed as part of foundational web development training and hands-on practice at SDAC Infotech.
