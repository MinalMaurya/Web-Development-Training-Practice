# E-Learning Website

A simple multi-page E-Learning website developed using HTML and CSS.

## Pages Included

- Home: Main landing page.
- About Us: Information about the website.
- Contact Us: Contact page.
- Login: User login interface.
- Registration: User registration interface.

## Technologies Used

- HTML5
- CSS3

## Features

- Multi-page website structure.
- Navigation between different pages.
- Login and registration forms.
- CSS-based styling.
- Simple and user-friendly page layouts.

## Project Structure

E-Learning-Website/
├── AboutUs.html
├── ContactUs.html
├── home.html
├── login.html
├── Registration.html
├── style.css
└── README.md

## How to Run

1. Open the E-Learning-Website folder in VS Code.
2. Open `home.html`.
3. Run it using Live Server or open it in a browser.
